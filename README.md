# Tech Hardware Store POS

## Description
A Point of Sale (POS) web application built using ASP.NET Core MVC for a Tech Hardware Store.

## Features
- Product Browsing
- Shopping Cart
- Quantity Management
- Item Removal
- Checkout & Payment
- Transaction History

## Technologies Used
- ASP.NET Core MVC
- C#
- Bootstrap
- Static In-Memory Repositories

## How to Run

1. Clone the repository
2. Open the solution in Visual Studio
3. Run the application

## Required Branches

- main
- feature/shopping-cart
- feature/checkout
